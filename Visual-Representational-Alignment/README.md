# 🧠 Investigating Representational Alignment in Visual Processing

**Computational Neuroscience | Neuromatch Academy**

## Project Overview

This project explores the relationship between visual information processing in the human brain and representations learned by artificial neural networks.

Using fMRI data from the **Kay natural images dataset**, we investigated how neural representations in different regions of the human visual cortex relate to features extracted from deep neural network models, particularly **CORnet-S**.

The project combines computational neuroscience, deep learning, and neural data analysis to better understand similarities between biological and artificial visual processing systems.

## Research Objectives

- Investigate representational similarities between human visual cortex activity and artificial neural network representations.
- Examine differences across visual regions of interest (ROIs).
- Analyze how representations vary across layers of deep neural networks.
- Visualize and compare representational structures using Representational Dissimilarity Matrices (RDMs).

## Dataset

**Kay Natural Images Dataset**

The dataset includes natural image stimuli and corresponding fMRI responses recorded from the human visual cortex.

These data allow comparisons between brain responses to visual stimuli and representations generated by computational vision models.

## Methodology

The project involved:

1. **Neural Data Analysis:** Working with fMRI responses across different visual cortex ROIs.
2. **Deep Learning Models:** Exploring visual representations extracted from convolutional neural networks, including CORnet-S.
3. **Representational Similarity Analysis (RSA):** Constructing and analyzing RDMs to compare representational patterns.
4. **Correlation Analysis:** Examining relationships between representations from different brain regions and neural network layers.
5. **Visualization:** Generating plots to interpret representational similarities and differences.
