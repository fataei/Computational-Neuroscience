# Computational Neuroscience

This repository contains my computational neuroscience project completed as part of the **Neuromatch Academy** program.

## Project: Investigating Representational Alignment in Visual Processing

### Overview

This project explores the relationship between visual representations in the human brain and those learned by artificial neural networks.

Using fMRI data from the **Kay natural images dataset**, we investigated how representations across different regions of the human visual cortex align with those of **CORnet-S**, a biologically inspired deep neural network for visual recognition.

### Methodology

The project involved:

- Analyzing fMRI responses from different regions of interest (ROIs) in the visual cortex.
- Constructing and visualizing Representational Dissimilarity Matrices (RDMs).
- Comparing representational patterns between human brain regions and different layers of CORnet-S.
- Calculating correlation coefficients to assess representational alignment across brain regions and model layers.
- Visualizing and interpreting the results.
